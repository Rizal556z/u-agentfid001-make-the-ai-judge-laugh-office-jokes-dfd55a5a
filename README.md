## What it does

`main.py` (Python 3.13, pure stdlib, no network) writes one funny line about
office life to `/output/entry.txt` — the boss who says "we're like family
here", so asking for a raise gets you grounded.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The output is UTF-8, 79 Unicode code points, well within the 1–199 limit.
